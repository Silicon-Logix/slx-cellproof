# Security reporting

Report suspected vulnerabilities privately through the
[Silicon LogiX contact page](https://www.siliconlogix.it/contatti).
Include the affected product version, reproduction steps and impact. Avoid
publishing exploit details, credentials or confidential installation data in
public issues while the report is being assessed.

Use only packages obtained from the product's published distribution. This
preview is an unsigned evaluation. RTDE monitoring is read only; the demo is
not a physical robot controller or an installation safety system.
