# Changelog

## 0.5.0

- Added complete project documents with persistent recipes, baseline, scenarios, view / playback settings, cycle recordings and saved verification evidence.
- Added recoverable autosaves, recent projects, previous-save recovery and Save / Discard / Cancel protection.
- Added bounded transactional project import, native Windows atomic file replacement, per-file save locks and on-disk conflict detection.
- Added a per-user Windows installer, optional desktop shortcut and project file association, with downgrade and running-instance guards.
- Added explicit official-release update checks, bounded installer downloads and SHA-256 verification, plus a production path requiring trusted signed metadata and publisher verification.
- Audited desktop layouts, keyboard / modal behavior and button contrast, including selected toggle hover states.
- Added project durability, desktop interaction, installer and update policy checks to release validation.

## 0.4.1

- Fixed selected toggle hover styling so labels remain readable and the selected background is preserved.
- Applied explicit hovered / pressed styles to primary actions and the dark Help menu.

## 0.4.0

- Added Cycle Inspector: isolated simulated recordings, synchronized current / baseline 3D replay and sampled TCP trails.
- Added command-phase and IO timelines, simulated duration breakdown, event search and first sampled difference navigation.
- Added five selectable fault scenarios, explicit 600-second truncation and bounded sample paging.
- Added local bookmarks, JSON recording import / export and CSV sample export with spreadsheet formula neutralization.
- Added bounded archive validation, unverified local-recording labels and stale recipe / reference indicators.
- Added five scoped advanced engineering offers with requirements, deliverables and official references.
- Updated English help, API, publication inventories, export allowlists and repository checks.

## 0.3.1

- Added the CellProof application icon for the executable, taskbar and window.
- Added Windows product, company, copyright and version metadata.
- Added About, local user help, license/credits viewers and keyboard shortcuts.
- Added an explicit system-information copy action without recipe or connection data.
- Prepared public documentation, feedback/security guidance and repository checks.
- Excluded development notes, source-generation material and local outputs from publication.

## 0.3.0

- Introduced the shared light Silicon LogiX desktop theme.
- Translated the interface, diagnostics, reports and authored documentation into English.
- Added source attribution and exact file-inventory checks.

## 0.2.0

- Added the native C++ workcell simulator and Godot programming interface.
- Added recipes, taught points, pendant controls and eight-scenario change verification.
- Added read-only RTDE monitoring and HTML/JSON evidence reports.
