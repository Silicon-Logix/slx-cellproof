# Feedback and contributions

Bug reports, usability feedback and feature proposals are welcome. Include the
CellProof version, operating system, steps to reproduce and expected/actual
behavior. The About window can copy a short system-information summary.

Use a minimal example and remove personal information, installation addresses
and confidential machine programs before attaching a file. Do not post private
keys or security-sensitive reports in a public issue.
